

| 브랜치 | 용도 |
|--------|------|
| `main` | — develop 브랜치에서 검증 후 최종 결과물만 merge |
| `develop` |  — 개발 결과물은 여기로 merge |

## 작업 흐름

1. `develop`에서 `feature/` 브랜치를 생성합
2. 작업 완료 후 `develop`으로 *Pull Request** 을 생성
3. 코드 리뷰 후 `develop`에 merge
4. 검증후 최종 결과물을 `develop` → `main`으로 merge
