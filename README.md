어느정도 통일감을 생각해서 잡다한 rule 파일 만들었는데 한번 봐주세요

## 브랜치

| 브랜치 | 용도 |
|--------|------|
| `main` | develop 브랜치에서 검증 후 최종 결과물만 merge |
| `develop` |  1차 개발 통합 merge |
| 개인 브랜치 | 개인별로 작업하기 위한 브랜치 예시) feat/AI/Task_1/yolo 브랜치, feat/FE/login 브랜치 |

개인작업 ------> 1차 통합 develop -----> 최종 결과 main

## 작업 흐름

1. `develop`에서 `feature/` 브랜치를 생성
2. 작업 완료 후 `develop`으로 *Pull Request** 을 생성
3. 코드 리뷰 후 `develop`에 merge
4. 검증후 최종 결과물을 `develop` → `main`으로 merge
