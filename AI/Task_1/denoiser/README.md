# Denoiser Module

## 1. 프로젝트 개요
본 모듈은 번호판 이미지에 대해 다양한 디노이징 기법을 적용하고,  
각 방법의 성능을 비교 및 분석하는 것을 목표로 한다.

---

## 2. 폴더 및 구조 (Directory Structure)
본 디렉토리는 각 디노이징 모델의 성격과 역할을 명확히 나누어 관리합니다.

- **`classical/`**: OpenCV 등을 활용한 전통적인 이미지 필터링(Gaussian, Median 등) 방식의 코드
- **`dncnn/`**: CNN 기반의 고전적 딥러닝 디노이징 모델 코드 및 가중치
- **`transformer/`**: Transformer 아키텍처를 응용한 디노이징 실험 코드
- **`nafnet/`**: (최종 채택) 색상 보존 능력과 연산 효율이 극대화된 NAFNet 기반의 컬러 디노이징 아키텍처, 학습 및 평가 코드
- **`data/`**: 원본 이미지에 인위적인 노이즈를 씌워 Clean/Noisy 이미지 쌍(Pair)을 생성하는 데이터셋 생성 스크립트
- **`pipeline/`**: 학습된 디노이저를 단일 이미지에 적용해 보는 공통 추론 파이프라인
- **`utils/`**: 공통적으로 사용되는 평가 보조 함수나 유틸리티 모음

---

## 3. 데이터 생성 방식
- 입력: YOLO로 분리된 번호판 이미지
- 처리: Grayscale 또는 RGB 이미지에 다양한 노이즈를 인위적으로 삽입
- 출력: clean / noisy 이미지 쌍으로 구성된 데이터셋
- 데이터셋 원본과 생성 결과는 용량 문제로 포함하지 않고, 재생성 가능한 스크립트와 설명만 보존한다.

---

## 4. 비교 대상 모델
- Classical (OpenCV 기반)
- DnCNN (CNN 기반 딥러닝 모델)
- Transformer 기반 디노이저
- **NAFNet (Color Denoising 특화)**

---

## 5. 평가 지표
- PSNR (Peak Signal-to-Noise Ratio)
- SSIM (Structural Similarity Index)
- 기타 필요 시 추가

---

## 6. 결과 비교
| Model        | PSNR | SSIM |
|-------------|------|------|
| Classical   |      |      |
| DnCNN       | 23.26| 0.53 |
| Transformer |      |      |
| **NAFNet**  | **25.49**| **0.66** |

모델별 정량 비교와 시각화 스크립트는 각 모델 폴더 및 `utils/`에 분리되어 있다.

---

## 7. 결론
- **흑백(Grayscale) 디노이징의 한계 극복**: 초기 DnCNN 기반의 흑백 이미지 디노이징을 시도하여 구조적 복원에는 성공했으나, 실제 컬러 환경(특히 파란색 전기차 번호판)에 적용 시 색상 왜곡 현상이 발생
- **컬러(Color) 데이터셋 학습**: 이를 해결하기 위해 입력 데이터셋 을 완전한 컬러 이미지로 전환하고, 컬러 채널 간의 상관관계를 학습하면서도 원본 색상을 유지할 수 있는 **NAFNet**을 도입
- **최종 분석**: 흑백 데이터로 학습된 기존 모델(DnCNN)을 컬러 데이터셋으로 학습한 NAFNet으로 대체한 결과, PSNR은 23.26dB에서 25.49dB로 상승하였고, 윤곽선 보존 능력을 나타내는 SSIM은 0.53에서 0.66으로 대폭 개선, 색상 왜곡 없이 고주파 노이즈만 선택적으로 제거하도록 학습해 **최종 파이프라인의 메인 디노이징 모듈**로 채택
